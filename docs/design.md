# Design System Document
 
## Theme Overview
Our design system utilizes a **light color mode**, prioritizing readability and a modern aesthetic.
 
## Colors
- **Primary Color:** `#0052CC` (a vibrant blue, ideal for calls to action and key interactive elements).
- **Neutral Color:** `#F8F9FA` (a soft, light grey providing a clean background for content).
 
## Typography
- **Headlines:** `manrope` - A clean, geometric sans-serif for strong, modern headings.
- **Body Text:** `inter` - A highly readable and versatile sans-serif, suitable for all body copy.
- **Labels:** `inter` - Consistent with body text for clear and concise labels.
 
## Shape & Form
- **Roundedness:** UI elements feature **moderate roundedness (2)**, offering a friendly yet professional appearance.
 
## Spacing
- **Spacing:** The system adopts **normal spacing (2)**, providing a balanced layout that is neither too dense nor overly expansive, ensuring good readability and visual comfort.
